# 矩阵运算与逆矩阵

## 一、矩阵乘法

**要点**：$A_{m\times n}B_{n\times p}=C_{m\times p}$，其中 $c_{ij}=\sum\limits_{k=1}^{n}a_{ik}b_{kj}$，即"左行乘右列"。注意 $AB\neq BA$（一般不可交换），且 $AB=O$ 推不出 $A=O$ 或 $B=O$。

**典型题型**：数值乘法、可交换条件的应用、$(AB)^T=B^T A^T$。

**例题 1**：设 $A=\begin{pmatrix}1&2\\3&4\end{pmatrix}$，$B=\begin{pmatrix}0&1\\1&0\end{pmatrix}$，求 $AB$ 与 $BA$。

解：$AB=\begin{pmatrix}2&1\\4&3\end{pmatrix}$，$BA=\begin{pmatrix}3&4\\1&2\end{pmatrix}$。可见 $AB\neq BA$。

sympy_check: `Matrix([[1,2],[3,4]])*Matrix([[0,1],[1,0]]) == Matrix([[2,1],[4,3]])`

**例题 2**：设 $A=\begin{pmatrix}1&1\\0&1\end{pmatrix}$，求 $A^2$ 并观察规律。

解：$A^2=\begin{pmatrix}1&2\\0&1\end{pmatrix}$。一般地 $A^k=\begin{pmatrix}1&k\\0&1\end{pmatrix}$，可由归纳法证明。

sympy_check: `Matrix([[1,1],[0,1]])**2 == Matrix([[1,2],[0,1]])`

## 二、逆矩阵

**要点**：若 $AB=BA=E$，则称 $B$ 为 $A$ 的逆矩阵，记作 $B=A^{-1}$，此时称 $A$ 可逆。可逆的充要条件是 $|A|\neq 0$（即 $A$ 非奇异），且逆矩阵唯一。二阶矩阵口诀"主对角交换、副对角变号、除以行列式"：$\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}=\dfrac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$（要求 $ad-bc\neq 0$）。高阶用初等行变换 $(A\mid E)\to(E\mid A^{-1})$。常用性质：$(A^{-1})^{-1}=A$，$(AB)^{-1}=B^{-1}A^{-1}$（顺序反写），$|A^{-1}|=\dfrac{1}{|A|}$，伴随矩阵满足 $A^{-1}=\dfrac{A^*}{|A|}$。

**典型题型**：求逆、解矩阵方程（$AX=B\Rightarrow X=A^{-1}B$，注意左乘还是右乘不可弄反）、伴随矩阵求逆、可逆性与参数讨论。解矩阵方程时，若 $X A = B$ 则 $X = B A^{-1}$，乘法方向由 $A$ 在方程中的位置决定。

**例题 1**：求 $A=\begin{pmatrix}1&2\\2&5\end{pmatrix}^{-1}$。

解：$|A|=1\times5-2\times2=1\neq 0$，故 $A$ 可逆，直接套二阶口诀：

$$A^{-1}=\begin{pmatrix}5&-2\\-2&1\end{pmatrix}$$

验算：$\begin{pmatrix}1&2\\2&5\end{pmatrix}\begin{pmatrix}5&-2\\-2&1\end{pmatrix}=\begin{pmatrix}1&0\\0&1\end{pmatrix}$。二阶求逆建议口算后必验算一次乘法，几秒钟就能确认，考场上这一步极划算。

sympy_check: `Matrix([[1,2],[2,5]]).inv() == Matrix([[5,-2],[-2,1]])`

**例题 2**：求上三角矩阵 $A=\begin{pmatrix}1&1&1\\0&1&1\\0&0&1\end{pmatrix}$ 的逆。

解：用初等行变换，对增广阵 $(A\mid E)$ 做消元：第一列只剩首元素为 1；第二列用第 2 行去消第 1 行，得第 1 行第二块处的 $-1$；第三列用第 3 行去消上面两行。整理得

$$A^{-1}=\begin{pmatrix}1&-1&0\\0&1&-1\\0&0&1\end{pmatrix}$$

验算：两矩阵相乘，第一行得 $(1,\,-1+1,\,0-1+1)=(1,0,0)$，第二、三行同理得单位向量，乘积为 $E$。上三角矩阵的逆仍是上三角矩阵，这个规律可以用来快速自查答案的形状。

sympy_check: `Matrix([[1,1,1],[0,1,1],[0,0,1]]).inv() == Matrix([[1,-1,0],[0,1,-1],[0,0,1]])`

## 三、矩阵的秩

**要点**：秩是最高阶非零子式的阶数，也等于行阶梯形中非零行的行数，记作 $r(A)$。求秩的标准流程是初等行变换化行阶梯形再数非零行。常用结论：$r(A^T)=r(A)$；$r(AB)\le\min\{r(A),r(B)\}$；若 $P$、$Q$ 可逆，则 $r(PAQ)=r(A)$，即可逆矩阵乘法不改变秩；$r(A+n\text{ 阶})\le\min\{m,n\}$；$A$ 为 $n$ 阶方阵时，$r(A)=n\Leftrightarrow|A|\neq0\Leftrightarrow A$ 可逆。秩还决定齐次方程组 $Ax=0$ 的解空间维数为 $n-r(A)$。

**典型题型**：求具体矩阵的秩、含参数矩阵讨论秩、用秩判线性方程组解的结构。含参数时的一般策略：先算行列式（方阵）或直接消元（非方阵），令其为零找参数临界值，再对临界值逐个验秩，避免"行列式为零就默认秩减一"的错误。

**例题 1**：求 $A=\begin{pmatrix}1&2&3\\2&4&6\\1&1&1\end{pmatrix}$ 的秩。

解：第 2 行是第 1 行的 2 倍，消元后得行阶梯形 $\begin{pmatrix}1&2&3\\0&-1&-2\\0&0&0\end{pmatrix}$，非零行 2 个，故 $r(A)=2$。

sympy_check: `Matrix([[1,2,3],[2,4,6],[1,1,1]]).rank() == 2`

**例题 2**：设 $A=\begin{pmatrix}1&2&3\\4&5&6\\7&8&a\end{pmatrix}$，问 $a$ 为何值时 $r(A)=2$？

解：先算行列式，按第一行展开：

$$|A|=1\cdot(5a-48)-2\cdot(4a-42)+3\cdot(32-35)=27-3a$$

令 $|A|=0$ 得 $a=9$。此时第 3 行 $=2\times$第 2 行 $-$ 第 1 行，前两行线性无关，故 $r(A)=2$；当 $a\neq 9$ 时 $r(A)=3$。

sympy_check: `Matrix([[1,2,3],[4,5,6],[7,8,a]]).det() == 27 - 3*a`

## 四、常见易错点

一是不交换律：拆含 $AB$ 与 $BA$ 的式子时不能随意交换次序，消去律也不成立，$AB=AC$ 且 $A\neq O$ 推不出 $B=C$，除非 $A$ 可逆。二是转置与求逆的次序：$(AB)^{-1}=B^{-1}A^{-1}$ 与 $(AB)^T=B^TA^T$ 都是"反序"，但一个戴逆号一个转置，不要混写。三是计算行列式展开时符号 $(-1)^{i+j}$ 最容易出错，含参数行列式算完后建议代回一个具体数复核。

## 小结

矩阵乘法是"行乘列"的线性组合压缩，逆矩阵是"运算的回退"，秩刻画矩阵的"有效维数"。三者联动的主线：$A$ 可逆 $\Leftrightarrow |A|\neq 0 \Leftrightarrow r(A)=n$。求逆优先用初等行变换，含参数讨论秩则先算行列式找临界值。
