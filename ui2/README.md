# MathForge v2 · 学生端 UI（ui2）

v2 练习闭环的用户界面：**两页结构**（今日练习 / 足迹统计）+ 填空表达式输入 + 拍照识别入口。
深色「Ink & Signal」视觉（off-black + 单一电蓝 accent），本地 KaTeX，无任何 CDN 外链，
390px 无横向溢出，动效全部尊重 `prefers-reduced-motion`。

## 页面结构

顶栏：MathForge 标识 + 页切换（今日 / 足迹统计）+ 当日打卡徽标（localStorage 诚实本地统计，服务端今日有作答也会回填）。

1. **今日练习**（默认）
   - 意图条：一句话点名考点（如「来一道进阶的拉格朗日」）→ `POST /v2/intent`；低置信不硬出题，给推荐 chips。冷启动（无记录）时自动退居二线并禁用，先做推荐基础题后解锁。
   - 复习清单：`GET /v2/review` → 按高数/线代/概率分组，掌握度条从 0 生长动画；卡片含最近题干 KaTeX 摘要与错因 tag；「练一题」走变式（带溯源）。
   - 空态：系统推荐 3 个基础族考点（`GET /v2/recommend-start`，零 API）做母题建画像。
   - 出题卡（同页展开）：溯源区（源题摘要 + 变化 chips + 知识点一致性）→ 题面 KaTeX → 作答。
   - **填空**：`POST /v2/turn` 出题 → 提交前 `POST /v2/parse-check` 预检（不可解析不记事件，输入框抖动提示）→ `POST /v2/answer` SymPy 等价判分。结果卡：verdict + 错因 + 策略理由（「为什么是这道」）+ **正确答案与解法（折叠，答错默认展开）** + 归因修正 chips（就地确认）。
   - **解答题**：仅当 kp.qtypes 含 `solution`；步骤输入 + 折叠标准解答 + 三档自评 `POST /v2/selfassess`（机器不判步骤分，D022 红线）。
   - **拍照识别答案**（可选）：`POST /v2/photo-recognize` 代理到识别 sidecar（mathforge_ingest.service:8600）；识别结果只作回填候选，标注「AI 识别，请核对后再提交」；sidecar 未启动优雅降级。
   - 「再练一题」**按策略执行**：决策动作含 kp_target/难度时按钮变「按策略练：先补前置/同类题降档再练」等，真实切换考点或难度。
2. **足迹统计**（只读）：热力图（182 天，今日描边）/ 当日明细（逐条 KaTeX）/ 掌握度分布 / 错因分布 / 薄弱模式（规则蒸馏）/ 策略时间线折叠。

## 输入归一化（2026-09-12）

提交与判分前统一过 `verify.normalize_expr`：π ² √ × ÷ − ∞ ≤ ≥ 全角数字/运算符/括号/中文标点
自动翻译成 SymPy 形态——学生写 `π/2`、`√2/2`、`x²`、`0.5` 都能直接判，不再要求会写 SymPy 语法。

## 依赖

- 本地 KaTeX（复用 `/ui/vendor/katex/`），无其它依赖
- 拍照识别为可选 sidecar：见 `docs/2026-09-12_夜间优化/02_更新说明.md` §5
